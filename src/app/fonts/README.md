# Inter Variable

`InterVariable.woff2` is the unmodified upright variable font from the official
[Inter 4.1 release](https://github.com/rsms/inter/releases/tag/v4.1),
`web/InterVariable.woff2` in `Inter-4.1.zip`.

Font version: `4.001;git-9221beed3`. Includes weight (100–900) and optical size
(14–32) axes. Served locally through `next/font/local`; the homepage uses
automatic optical sizing and the `cv01` / `ss03` stylistic features.
